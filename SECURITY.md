# Security

Report vulnerabilities privately to **help@crixin.com** with "security" in the subject. Please do not open a public issue for anything exploitable.

What to expect: an acknowledgement within 3 business days, a fix or mitigation plan within 14 days for confirmed issues, and credit in the changelog if you want it.

Scope: this repository (the `crixin` npm package, the marketing site and its serverless functions) and the hosted Voice MCP at `crixin-platform.vercel.app/api/mcp`.

No secrets live in this repository. Configuration is environment-driven; see `.env.example` files and the README.
